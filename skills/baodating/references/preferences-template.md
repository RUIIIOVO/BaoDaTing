# Optional host-local preferences template

This is a blank generic template, not a record about any user. Using the skill does not require a preference file. If the user wants persistent preferences, keep the completed record in a host-supported private location outside the public repository and installed skill. Do not invent a universal filesystem path or automatic memory integration.

Read only preferences the host makes available with appropriate authorization. Current task instructions override them. Do not promote one purchase, one travel date, or a discarded candidate into a permanent rule. Ask about a stable preference only when remembering it would be useful; do not repeatedly ask to save routine decisions.

```text
Preferred research language or region: unspecified
Desired explanation depth: unspecified
Usual constraints or compatibility needs: unspecified
Cost preferences and scope of application: unspecified
Acceptable setup, learning and maintenance effort: unspecified
Allowed research channels: unspecified
Account/session isolation requirements: unspecified
Foreground/background interaction policy: follow host configuration
Research time or spend limit: unspecified
Evidence of preference: user statement / date / applicable context
Uncertain or task-specific information: unspecified
```

Store no passwords, tokens, cookies, account handles, browsing history, or raw chat transcripts in a preference record. Describe a permission or requirement without embedding credentials. Unknowns stay unspecified. Keep public examples generic and never commit a filled-in private record.
